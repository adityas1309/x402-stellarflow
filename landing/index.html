03 / Agent workflow

The real product runs in the agent loop.

The web checkout is optional. The primary integration is an MCP server that lets Claude, Cursor, Codex, or another MCP client discover a paid tool and authorize each call from a testnet agent wallet.

01 / INSTALL

Run the MCP server

Install and build the terminal package. It speaks MCP over stdio, so your AI client can launch it as a local tool server.

02 / CONNECT

Provision the agent wallet

npx x402-mcp init creates the testnet payer wallet and stores its local signing configuration.

03 / CALL

Ask the agent for data

The model calls a paid MCP tool. The server requests the API, receives HTTP 402, and reads the exact USDC requirement.

04 / SETTLE

Pay, retry, return

The agent signs the payment, retries with X-Payment, the facilitator settles on Stellar testnet, and the tool returns the result.

06 / Product questions

Clear by design.

Is this a real service?

Yes. The endpoint fetches current public stories, returns a transparent lexicon-based signal, and charges 0.05 USDC before releasing the response. The payment settles on Stellar testnet; no production funds are involved.

Which wallets can connect?

Stellar Wallets Kit opens a wallet selector for Freighter, xBull, Albedo, WalletConnect, Lobstr, Rabet, Hana, and other supported Stellar wallets. The selected wallet signs both the trustline transaction and x402 authorization.

Does the browser button make a payment?

Yes. After connecting a Stellar testnet wallet, the payment button asks it to approve exactly 0.05 USDC, retries the protected API request when testnet timing requires a fresh authorization, and links to confirmed activity.

What does x402 add?

x402 turns HTTP 402 into machine-readable payment requirements. Agents can discover the price, sign a payment, retry the request, and receive live public-signal data without a dashboard or API key.

Why testnet?

Testnet gives the same Stellar and Soroban mechanics without real financial risk. The live product is intentionally configured for testnet.
